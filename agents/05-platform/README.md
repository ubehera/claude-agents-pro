# Tier 05: Platform Agents

Platform agents focus on developer experience, workflow automation, and productivity tooling. Use them to streamline development workflows, automate repetitive tasks, and optimize team productivity.

## When to Use Platform Agents

Use these agents when you need to:
- **Automate Git workflows** with branch strategies and PR automation
- **Optimize developer experience** across tooling and processes
- **Streamline team workflows** with automation and conventions
- **Improve productivity** through tooling and process optimization

## Available Agents

### [git-workflow-manager](git-workflow-manager.md)
Git workflow automation specialist for branch strategies, commit conventions, PR automation, release management, and repository hygiene.

**Use when:** Git workflow setup, branch strategy design, PR automation, release processes.

### [dx-optimizer](dx-optimizer.md)
Developer experience optimization specialist for improving development workflows, tooling, onboarding, and team productivity.

**Use when:** Developer productivity, onboarding improvement, tooling optimization, workflow streamlining.

| If you need to... | Use this agent |
|-------------------|----------------|
| Design branch strategies | **git-workflow-manager** |

| Improve developer onboarding | **dx-optimizer** |
| Optimize development tooling | **dx-optimizer** |
| Set up release processes | **git-workflow-manager** |

## Common Combinations

**New Team Setup:**
1. `git-workflow-manager` → Branch strategy and PR conventions
2. `dx-optimizer` → Development environment and onboarding
3. `devops-automation-expert` → CI/CD pipeline setup
4. `observability-engineer` → Development metrics

**Productivity Improvement:**
1. `dx-optimizer` → Identify friction points
2. `git-workflow-manager` → Streamline Git workflows
3. `devops-automation-expert` → Automate repetitive tasks

**Repository Modernization:**
1. `git-workflow-manager` → Update branch strategies
2. `dx-optimizer` → Improve tooling and scripts
3. `code-reviewer` → Establish review standards

## Best Practices

- **Start with assessment**: Identify pain points before optimizing
- **Automate gradually**: Introduce automation incrementally
- **Document conventions**: Make workflows discoverable
- **Measure impact**: Track productivity metrics

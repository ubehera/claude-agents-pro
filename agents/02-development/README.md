# Tier 02: Development Agents

Development agents are language and platform specialists who bring deep expertise in specific technology stacks. Use them for implementation work that requires idiomatic code and framework-specific best practices.

## When to Use Development Agents

Use these agents when you need to:
- **Write idiomatic code** in a specific language
- **Leverage framework features** correctly
- **Follow language-specific patterns** and conventions
- **Optimize for platform capabilities**
- **Debug language-specific issues**

## Available Agents

### [typescript-architect](typescript-architect.md)
Senior TypeScript architect for Node.js 20+, Bun, Deno, and modern frontend stacks (React 18, Next.js 14, Remix). Specializes in advanced typing, runtime safety, build tooling, and monorepo design.

**Use when:** TypeScript platform upgrades, API contracts, build optimization, DX improvements.

### [angular-expert](angular-expert.md)

## Common Combinations

**Full-Stack TypeScript:**
1. `typescript-architect` → Backend API with Node.js
2. `frontend-expert` → React/Next.js frontend
3. `test-engineer` → End-to-end testing

**Python Data Platform:**
1. `python-expert` → FastAPI services
2. `data-pipeline-engineer` → ETL workflows
3. `database-architect` → Data modeling

**Mobile App Development:**
1. `mobile-specialist` → Native/cross-platform app
2. `api-platform-engineer` → Backend API design
3. `frontend-expert` → Web companion app

## Best Practices

- **Match expertise to task**: Use language specialists for idiomatic implementations
- **Combine with foundation**: Pair with `code-reviewer` for quality validation
- **Stay current**: These agents know latest versions and patterns
- **Cross-platform**: Use `mobile-specialist` for unified iOS/Android strategy
